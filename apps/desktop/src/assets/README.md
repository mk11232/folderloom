# Folderloom icon

Generated for Folderloom from the requested concept: loose strands woven through a loom into a complete folder. The source artwork is `folderloom.png`; no private source data is part of the artwork.

Native PNG and ICNS derivatives in `src-tauri/icons` are generated with the Tauri icon command. The source asset is retained so other platform sizes can be generated when those platforms are supported.
