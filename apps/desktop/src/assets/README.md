# Folderloom icon

The source artwork is `folderloom.png`, supplied and selected by the user on November 6, 2026. The selected revision uses layered shading. Three cyan, blue, and gold folders with matching document symbols flow into a teal destination folder. The supplied image is used unchanged; no private source data is part of the artwork.

Native PNG and ICNS derivatives in `src-tauri/icons` are generated with the Tauri icon command. Retain the source asset for other platform sizes. The supplied raster has small edge artifacts; this build intentionally uses the selected design rather than silently replacing it with a generated interpretation.
